# Shims

Things I've built with [Shim](https://shimbrowser.com), the browser that lets you change any website and build your own pages on top of the sites you use. Each folder holds a `.shim` file you can import, and its source.

| | What it is |
| --- | --- |
| [Crate](crate) | A music-sourcing page for DJs: one search across Soundeo, Beatport, SoundCloud and YouTube, DJ play counts from 1001tracklists, and playlists shared with friends |

## Use one

1. Install [Shim](https://shimbrowser.com).
2. Download the `.shim` file from a folder here.
3. In Shim, open the Library, choose **Import**, and pick the file.

Each folder's README covers what that one needs.
